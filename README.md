# 🏴‍☠️ BACKSTAGE DU MONDE

**Un projet animé, poétique et politique par [De Cœur Hackers]([https://youtube.com/@decoeurhackers](https://www.youtube.com/@DeCoeurHackers))**  
Pour comprendre les flux invisibles qui gouvernent nos vies : énergie humaine, pouvoir, argent, attention...

🎥 Chaque épisode = une scène animée  
📚 Chaque scène = un dossier GitHub de sources et de symboles
